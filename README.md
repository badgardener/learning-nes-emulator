# NES Emulator

A Nintendo Entertainment System (NES) emulator written as a **learning project**.

This project is currently in its **very early stages**. The main goal is to learn more about low-level programming, emulation, computer architecture, and how the NES works internally.

## Status

**Early development / Learning project**

This emulator is just getting started, so many parts are incomplete and things may change significantly as development continues.

## Goals

- Learn how NES hardware works
- Understand CPU, memory, PPU, APU, and cartridge emulation
- Improve low-level programming skills
- Experiment with emulation techniques
- Eventually run NES software accurately

Thanks to [NESDev.org](https://www.nesdev.org/wiki/Nesdev_Wiki).

## Development

The project is being built from the ground up for educational purposes. It is not intended to be a production-ready emulator at this stage.

Expect bugs, incomplete features, and frequent changes.

## Why?

Rather than simply using an existing emulator, this project is an opportunity to understand **how an emulator actually works** by implementing one step by step.
